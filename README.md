# Лендинг «Сайт для АМДЦ» — персональное предложение

Продающая страница, которая продаёт клинике АМДЦ (ул. Орбели, 19, Санкт-Петербург)
разработку нового сайта. Та же фактура, что в `projects/amdc-stomatologiya`
(презентация не менялась), но переложенная в лендинг-«Атлант» на 16 блоков.

Статика: ни сборки, ни бэкенда. Открыть `index.html` — и всё работает.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | сам лендинг, 16 блоков |
| `privacy.html` | политика конфиденциальности под 152-ФЗ (реквизиты — подставить) |
| `assets/style.css` | дизайн-система, вёрстка, адаптив и стили печати |
| `assets/fonts.css` + `assets/fonts/` | Bitter, Golos Text и IBM Plex Mono — 10 файлов |
| `смыслы.md` | смысловая карта: ЦА, боли, оффер по 4U, структура, запасные заголовки |

Шрифты лежат файлами, сторонние CDN не дёргаются: страница открывается
и без интернета у шрифтового сервиса.

## Дизайн

Палитра взята из презентации, которую собственник уже видел: та же
больничная синь и та же тёплая бумага, чтобы лендинг читался как
продолжение разговора, а не как письмо от другой компании.

Страница собрана не как корпоративный лендинг, а как разворот документа:
номер раздела вынесен на поле, заголовки набраны серифом, цифры —
моноширинным с табличными нулями, чтобы столбики сходились. Тени почти
нет — бумага не парит над столом.

| Слой | Решение |
|---|---|
| Цвет | Синь `#00639F` на тёмных полосах (`#00426D` — на самых глубоких), тёплая бумага `#EFE9DA` на светлых |
| Акцент | Терракота `#E03B22` — **только кнопки и полоса прокрутки**. Больше нигде крупной заливки нет, иначе кнопка перестаёт быть единственным ярким пятном |
| Оценки | Мята `#2FE0A0` — работает, терракота — сломано, золото `#F2C56B` — наполовину. В оценках терракота живёт только заливкой-тинтом и волоском |
| Заголовки | Bitter — слэб-сериф, «документальный» |
| Текст | Golos Text — гротеск с родной кириллицей |
| Цифры и рубрики | IBM Plex Mono с `tabular-nums` |

Фактура: на светлых полосах бумажное зерно (SVG-турбулентность, 5%),
на тёмных — синяя миллиметровка, растворяющаяся к низу полосы.

Весь цвет собран в `:root` файла `assets/style.css`. Менять оттенки нужно
там: ниже по файлу везде стоят переменные, а не хексы.

### Оживление

Ничего лишнего и всё отключается через `prefers-reduced-motion`:

- полоса прочитанного вверху, шапка твердеет после 40 px прокрутки;
- блоки появляются на 14 px и за 0,6 с, лесенкой не длиннее четырёх шагов;
- полосы опроса дорисовываются, когда доезжают до экрана;
- липкая кнопка на телефоне выезжает, только когда первый экран ушёл.

Скрипт — 130 строк без библиотек. Если он не выполнится, ничего не
спрячется: `data-rise` проставляется тем же скриптом.

## Как работают формы

Бэкенда на GitHub Pages нет, поэтому заявка не отправляется на сервер:
скрипт в конце `index.html` собирает готовое сообщение и открывает WhatsApp
на номер `79111112122`. Ничего не теряется и не требует хостинга с PHP.

Если появится сервер — замените обработчик на обычный `fetch` к своему
`lead.php` (как сделано в `dofamin-site/`) и добавьте `thanks.html`.

## Что поправить перед отправкой клиенту

1. **Телефон и почта.** Сейчас `+7 911 111-21-22` и `semenovmak111@gmail.com` —
   взяты из презентации. Меняются в `index.html` (шапка, подвал, липкая кнопка,
   константа `WA` в скрипте).
2. **Реквизиты в политике.** В `privacy.html` стоят пометки в квадратных скобках.
3. **Название клиники.** В тексте везде «АМДЦ» — официальное имя с их сайта.
   Если на созвоне представляются как «АМДИ», заменить по тексту.
4. **Цена.** Намеренно не названа: в блоке страхов сказано, что сумма
   озвучивается после прототипа. Если решите ставить вилку — блок 14.

## Проверка вёрстки

```bash
# полноэкранный скриншот; свой профиль Chrome, чужие процессы не трогаем
CHROME='/c/Program Files/Google/Chrome/Application/chrome.exe'
PROF="$(mktemp -d)/chrome-shot"; mkdir -p "$PROF"
"$CHROME" --headless=new --disable-gpu --no-sandbox --hide-scrollbars \
  --user-data-dir="$(cygpath -w "$PROF")" --virtual-time-budget=12000 \
  --window-size=1440,14000 --screenshot="$(cygpath -w "$PWD/shot.png")" \
  "file:///$(cygpath -w "$PWD/index.html")"
```

Уже меньше 500 px окно headless Chrome не делает — телефонную версию
снимайте на `--window-size=500,9000`, иначе картинку просто обрежет справа
и вёрстка покажется сломанной.
